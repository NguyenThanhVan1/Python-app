
## Nhắn tin

Mục **Nhắn tin** lưu cuộc trò chuyện vào `messages.json` trên GitHub. Mỗi người
có thể nhập tên hiển thị, gửi tin nhắn và bấm **Làm mới tin nhắn** để xem tin
mới. Đây là kiểu chat gần thời gian thực bằng thao tác làm mới, không phải
WebSocket; GitHub phù hợp với cuộc trò chuyện nhỏ, không nên dùng cho dữ liệu
nhạy cảm hoặc lượng tin nhắn lớn.
